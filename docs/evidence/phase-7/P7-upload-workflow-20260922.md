## History export limitation

The history API returns the completed reviews and exact correction reasons.
The frontend now retains an explicit **Save history JSON** link as a fallback,
instead of silently discarding the blob after one second. It releases the old
blob when replaced or unmounted, and hides links for other selected documents.
The message says the history is ready; it does not claim the file was saved.

Automatic and explicit-link download-event waits both timed out in the available
in-app browser. The exact expected files were absent from the default Downloads
directory. Browser delivery therefore remains **unverified**. This run does not
establish whether the limitation is in the application or browser integration.
Do not mark this check complete based on HTTP success or DOM tests.
